## 2. Typography

- **Display / headlines:** `Fraunces` (variable serif, opsz 9..144, wt 400–800)
- **Body / UI:** `Manrope` (wt 300–800)
- **Mood:** editorial, confident, bold, modern — not corporate SaaS

**Why this pair (overriding the skill's Plus Jakarta Sans default):**
- CLAUDE.md explicitly bans Inter/Roboto/Arial — Plus Jakarta Sans reads the same.
- Fraunces' opsz axis gives a true display-vs-text contrast at large sizes.
- Manrope keeps body copy tight, geometric, and unmistakably modern.

**Loading:** use `next/font/google` in `app/(marketing)/layout.tsx` — not `@import url(...)`.
Hosting fonts via `next/font` self-hosts them at build time (zero network on render,
no FOUT, no Google CSS request).

**Scale:** `clamp()`-based fluid scale via `--fs-h1 / h2 / h3 / xl / lg / body / eyebrow`.

## 5. Motion

- **Duration:** 150–300ms for micro; 600–900ms for entrance reveals.
- **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (custom `--ease-out`) — never `linear`.
- **Animate sparingly:** 1–2 key elements per viewport (skill rule: "Excessive Motion").
- **Parallax:** opt-in via `useParallax` hook; disabled at `<768px` and on `prefers-reduced-motion`.
- **MUST honor `prefers-reduced-motion: reduce`** — drop all transitions/transforms.

## 7. Component Norms

**Buttons** — `mk-btn` + `mk-btn-primary` (gold gradient) or `mk-btn-ghost` (outline).
- Min 44×44px touch target.
- `cursor: pointer` required.
- Hover: 2px Y lift + shadow grow. **Never `scale()` on hover** (layout shift).
- `:focus-visible` ring: 2px gold offset (must add — see §9 todo).

**Cards** — surface bg, 1px gold-tinted border, 12–20px radius, gold-tinted lift on hover.

**Nav** — fixed, transparent → frosted glass past 60px scroll (`useScrolled`).

**Icons** — SVG only, 24×24 viewBox, never emoji.

---

## 8. Accessibility — Non-negotiable

- Color contrast ≥ 4.5:1 (gold-on-navy passes AAA)
- `aria-label` on every icon-only button (nav toggle, scroll indicator)
- `aria-expanded` on the mobile menu toggle
- `aria-hidden="true"` on purely decorative SVGs and background layers
- Visible `:focus-visible` rings on all interactive elements
- `prefers-reduced-motion` honored everywhere
- Tab order matches visual order
- Form labels via `<label for>`

---

## 9. Anti-Patterns (Do NOT Use)

From skill defaults:
- ❌ Light mode default (this is a dark-mode site)
- ❌ Slow rendering
- ❌ Emojis as icons
- ❌ Missing `cursor: pointer`
- ❌ Layout-shifting hovers (`scale()`)
- ❌ Low-contrast text (<4.5:1)
- ❌ Instant state changes (no transition)
- ❌ Invisible focus states

ChaptOS-specific:
- ❌ Purple gradients — generic AI-slop look (CLAUDE.md)
- ❌ Inter / Roboto / Arial (CLAUDE.md)
- ❌ Green CTA (`#22C55E`) — skill default; replaced with gold gradient
- ❌ Generic SaaS "circle + checkmark" feature lists — this is a serif-led editorial site
- ❌ `<img>` tags — use `next/image`
- ❌ `@import url(...)` for Google Fonts — use `next/font/google`

## 10. Pre-Delivery Checklist

Visual quality:
- [ ] No emojis as icons
- [ ] All icons from one set (custom inline SVG for marketing — keep stroke-width consistent at 1.8)
- [ ] Hover states don't shift layout
- [ ] Theme colors used directly (not `var()` wrapping another `var()`)

Interaction:
- [ ] `cursor: pointer` on all clickable elements
- [ ] Hover feedback visible (color/shadow/border)
- [ ] Transitions 150–300ms (micro), 600–900ms (entrance)
- [ ] `:focus-visible` rings on buttons + nav links

Motion:
- [ ] `prefers-reduced-motion: reduce` removes all transitions/animations
- [ ] Parallax disabled on `<768px`
- [ ] 1–2 animated elements per viewport, not all

Layout:
- [ ] Floating nav has `top` offset and proper spacing
- [ ] Hero content not hidden behind fixed nav (`padding-block: var(--space-32)` accounts for it)
- [ ] Container `max-w: 1200px` consistent
- [ ] Tested at 375 / 768 / 1024 / 1440

Next.js:
- [ ] Fonts via `next/font/google`, not `@import`
- [ ] Images via `next/image`
- [ ] `metadata` set in root layout
- [ ] App Router everywhere

Accessibility:
- [ ] Alt text / aria-label on every non-decorative image and icon-button
- [ ] Color is not the only indicator
- [ ] Tab order matches visual order
